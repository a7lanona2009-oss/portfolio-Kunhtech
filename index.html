Sample Question — Domain 4 · Security Operations

"A security analyst is reviewing logs and notices that a user account that was disabled three months ago is still generating authentication attempts against internal systems every hour, on the hour. The analyst confirms the account has no active sessions. Which of the following BEST describes this activity, and what should the analyst do FIRST?"
✅ الشرح التفاعلي بالعربي

🔑 الكلمات الدالة: disabled account + authentication attempts + scheduled / every hour

💡 التشخيص: هذا النشاط يشير إلى وجود scheduled task أو script مبرمج يستخدم credentials الحساب المعطل — وهو نمط شائع في هجمات persistence.

🎯 الإجابة الصحيحة: يجب على المحلل أولاً isolate المصدر وتحديد الـ system التي تُولِّد هذه المحاولات، ثم فحصها بحثاً عن malware أو مهام مجدولة غير مصرح بها.
